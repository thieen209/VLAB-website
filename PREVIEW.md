# VLAB local preview

Open http://127.0.0.1:4178/ while the preview is running.
To restart later, run `npm start` from this folder. Node.js is the only requirement; no build or dependency installation is needed.

Seven pages: homepage, labs, Kit, Android download, vision, terms and privacy. Vietnamese and English share the same layouts. The labs include four independent 2D principle demonstrations.

The Kit page provides a contact dialog; there is no form or generated email message. Light/dark mode remembers the selection and switches the header and footer logo variants. The tab icon uses the white icon-only variant. “Tải VLAB” opens the download page with a direct public GitHub APK link, build details and installation steps. The former video placeholder now shows a clean Unity room capture. The footer includes a remembered motion setting.

Images in `assets/images/project` come from the VLAB Unity project, the team photograph, the project report and the architecture diagram. The controller is a report illustration, not a product photograph. `glasses-v2.webp` is an AI-generated future concept, not current hardware.

The official bilingual legal articles remain preserved. See README.md for the supplied source documents.

User-supplied Physics and Chemistry screenshots replaced the previous lab imagery on 2026-09-10. The vision page now describes future AI guidance, virtual assistance and tutoring.
